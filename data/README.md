# Data
The dataset (~100 MB) is not stored in this repo. Run:

```bash
python scripts/download_data.py
```

Source: [Credit Card Fraud Detection – ULB / Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) (Open Database License). 284,807 anonymized card transactions from European cardholders over two days in September 2013.
